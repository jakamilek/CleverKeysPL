# Specjalistyczne warstwy słownika CleverKeys

## Budownictwo i drogownictwo

Warstwa obejmuje terminologię używaną w:

- projektowaniu dróg,
- budowie i utrzymaniu nawierzchni,
- robotach ziemnych,
- infrastrukturze drogowej,
- obiektach inżynierskich.

Priorytety:

1. słowa często używane w dokumentacji technicznej,
2. terminy spotykane w komunikacji zawodowej,
3. skróty branżowe po osobnej weryfikacji.

Źródła będą oceniane pod kątem licencji i jakości przed importem do głównej bazy.

Przykładowe otwarte źródła do analizy:
- dane publiczne administracji,
- klasyfikacje techniczne,
- otwarte słowniki i korpusy.
