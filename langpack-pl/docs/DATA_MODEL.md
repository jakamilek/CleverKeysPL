# Model danych CleverKeys PL

## Format źródłowy

Podstawowym formatem roboczym będzie CSV.

Przykład:

word,category,frequency,priority,profile

## Kategorie

- core
- engineering
- legal_admin
- technology
- phrases
- abbreviations

## Frazy

Frazy wielowyrazowe są przechowywane oddzielnie, np.:

- decyzja środowiskowa
- specyfikacja techniczna wykonania i odbioru robót
- zezwolenie na realizację inwestycji drogowej

## Skróty

Skróty zawodowe posiadają własny moduł wraz z rozwinięciami.
