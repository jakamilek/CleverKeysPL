# CleverKeys PL Professional

## Cel projektu

Projekt tworzy otwarte, audytowalne i modułowe zasoby językowe dla CleverKeys.

Założenie:

źródła danych → walidacja → ranking → profile → pakiet językowy

## Profile

- standard_pl
- engineering_pl
- engineering_legal_pl
- legal_admin_pl
- it_pl

## Warstwy danych

- core — język ogólny
- engineering — drogownictwo, budownictwo, geotechnika
- legal_admin — prawo i administracja
- technology — IT
- phrases — frazy wielowyrazowe
- abbreviations — skróty branżowe

## Zasada jakości

Słowo powinno być oceniane przez częstotliwość, poprawność i przydatność w danym profilu.

Celem nie jest największy słownik, lecz najbardziej użyteczny pakiet.
